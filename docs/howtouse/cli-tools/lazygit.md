# lazygit — Git TUI クライアント

ターミナルで動作する Git の TUI。ステージ/コミット/プッシュ/ブランチ操作を高速に行える。

> 設定: `modules/home-manager/git.nix`
> delta がページャーとして自動適用される (side-by-side diff)。

## 起動

```bash
lazygit       # カレントディレクトリの Git リポジトリで起動
```

## 画面構成

```
┌── Status ──┬── Files (Staged/Unstaged) ──────────────────┐
│             │                                              │
├── Branches ─┤  (メインパネル: 選択中の項目の詳細/差分)     │
│             │                                              │
├── Commits ──┤                                              │
│             │                                              │
├── Stash ────┤                                              │
│             │                                              │
└─────────────┴──────────────────────────────────────────────┘
```

左サイドバーにパネルが縦に並び、右側にメインビュー (差分など) が表示される。

## パネル間移動

| キー | 操作 |
|------|------|
| `1`~`5` | パネルを番号で直接切替 (1: Status, 2: Files, 3: Branches, 4: Commits, 5: Stash) |
| `Tab` / `Shift+Tab` | 次/前のパネル |
| `h` / `l` | パネル間を左右に移動 |
| `j` / `k` | パネル内のアイテムを上下に移動 |
| `[` / `]` | メインビュー内のタブ切替 (Diff / Patch 等) |

## Files パネル (2)

### ステージング

| キー | 操作 |
|------|------|
| `Space` | ファイルをステージ/アンステージ |
| `a` | 全ファイルをステージ/アンステージ (トグル) |
| `Enter` | ファイルの差分をハンク単位で表示 → ハンク単位でステージ |
| `d` | ファイルの変更を破棄 (checkout) |

### ハンク単位のステージング

```
1. Files パネルでファイルを選択して Enter
2. j/k でハンク間を移動
3. Space でハンクをステージ/アンステージ
4. v で行選択モード → 行単位でステージ
5. Escape で戻る
```

### コミット

| キー | 操作 |
|------|------|
| `c` | コミット (メッセージ入力) |
| `C` | エディタでコミットメッセージを編集 |
| `A` | 直前のコミットに amend |
| `S` | スカッシュ選択 (fixup 用) |

## Branches パネル (3)

| キー | 操作 |
|------|------|
| `Space` | ブランチを checkout |
| `n` | 新しいブランチを作成 |
| `d` | ブランチを削除 |
| `M` | 選択ブランチを現在のブランチにマージ |
| `r` | 選択ブランチの上に現在のブランチをリベース |
| `P` | プッシュ |
| `p` | プル |
| `f` | フェッチ |

## Commits パネル (4)

| キー | 操作 |
|------|------|
| `Enter` | コミットの詳細 (変更ファイル一覧) を表示 |
| `s` | スカッシュ (1つ前のコミットに統合) |
| `f` | fixup (メッセージを破棄してスカッシュ) |
| `r` | コミットメッセージを reword |
| `e` | コミットを edit (rebase --interactive) |
| `d` | コミットを削除 (rebase) |
| `Ctrl+j` / `Ctrl+k` | コミットの順序を入れ替え |
| `g` | リセットオプション (soft/mixed/hard) |
| `t` | タグを作成 |
| `y` | コミットハッシュをコピー |

## Stash パネル (5)

| キー | 操作 |
|------|------|
| `Space` | stash を apply |
| `g` | stash を pop |
| `d` | stash を削除 |

## グローバル操作

| キー | 操作 |
|------|------|
| `?` | キーバインドヘルプ |
| `/` | 検索 (現在のパネル内) |
| `+` | 前/次の検索結果 |
| `x` | メニュー (その時点で使える操作一覧) |
| `@` | コマンドログ (実行された git コマンド一覧) |
| `z` | Undo (直前の操作を取り消し — reflog ベース) |
| `q` | 終了 |
| `Escape` | キャンセル / 1つ前に戻る |

## delta 連携

lazygit 内の差分表示は自動的に delta が適用される。

- side-by-side diff で見やすい
- シンタックスハイライト付き
- 行番号表示あり

## ワークフロー

### 基本: 変更をコミットする

```
1. lazygit を起動
2. Files パネル (2) で変更ファイルを確認
3. Space でステージ (または a で全部)
4. c でコミットメッセージを入力
5. P でプッシュ
```

### ハンク単位の精密なステージング

```
1. Files パネルでファイルを選択
2. Enter でハンクビューに入る
3. j/k でハンクを移動しながら Space でステージ
4. v を押して行選択モードにし、特定の行だけステージ
5. Escape → c でコミット
```

### インタラクティブリベース

```
1. Commits パネル (4) に移動
2. 編集したいコミットまで移動
3. e で edit マーク → 自動的にリベースが始まる
   s でスカッシュ / f で fixup / d で削除
4. Ctrl+j/k でコミット順序を変更
```

### コンフリクトの解決

```
1. マージ/リベース中にコンフリクトが発生
2. Files パネルにコンフリクトファイルが表示される
3. Enter でコンフリクト箇所を表示
4. 上下矢印でコンフリクトマーカー間を移動
5. Space で「ours」「theirs」「both」を選択
6. 解決後 Space でステージ → コンフリクト解消のコミットまたは rebase --continue
```

### 直前のコミットを修正する

```
1. Files パネルで追加の変更をステージ
2. A で amend (メッセージを維持して変更を追加)
   または Commits パネルで r を押してメッセージのみ変更
```
