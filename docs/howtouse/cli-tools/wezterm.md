# wezterm — GPU 加速ターミナルエミュレータ

tmux 不要のターミナル多重化環境。Leader キー体系でペイン/タブ/ワークスペースを管理する。

> 設定: `modules/home-manager/gui/wezterm/wezterm.lua` (Nix モジュール側は `modules/home-manager/gui/wezterm.nix`)

## Leader キー

**`Ctrl+S`** が Leader キー (tmux の prefix に相当)。押してから 2 秒以内に次のキーを入力する。

以下の表記で `<Leader>x` は「`Ctrl+S` を押して離してから `x` を押す」を意味する。

## キーバインド一覧

### ペイン操作

| キー | 操作 |
|------|------|
| `<Leader>s` | 水平分割 (上下に分ける) |
| `<Leader>v` | 垂直分割 (左右に分ける) |
| `Ctrl+h/j/k/l` | ペイン間移動 (Neovim と共通: smart-splits) |
| `Alt+h/j/k/l` | ペインリサイズ (Neovim と共通: smart-splits) |
| `<Leader>e` | ペインを時計回りにローテーション |
| `<Leader>E` | ペインを反時計回りにローテーション |
| `<Leader>x` | 現在のペインを閉じる (確認あり) |
| `Ctrl+Shift+Z` | ペインをズーム (トグル) |

### タブ操作

| キー | 操作 |
|------|------|
| `<Leader>c` | 新しいタブを作成 |
| `<Leader>n` | 次のタブ |
| `<Leader>N` | 前のタブ |
| `<Leader>X` | 現在のタブを閉じる (確認あり) |
| `Ctrl+Shift+1`~`9` | タブを番号で切替 |

### ワークスペース

| キー | 操作 |
|------|------|
| `<Leader>W` | ワークスペース一覧を表示・切替 |
| `<Leader>R` | 現在のワークスペースの名前を変更 |

ワークスペースはタブのグループ。プロジェクトごとにワークスペースを分けると便利。

### シェル行編集 (Leader 経由)

| キー | 操作 | 相当する操作 |
|------|------|-------------|
| `<Leader>0` | 行頭に移動 | `Ctrl+A` |
| `<Leader>A` | 行末に移動 | `Ctrl+E` |
| `<Leader>d` | カーソルより前を削除 | `Ctrl+U` |
| `<Leader>w` | 次の単語へ移動 | `Meta+F` |

> Neovim 内では Neovim のキーバインドが優先されるため、これらは Neovim 外のシェルプロンプトで有効。

### 透過度

| キー | 操作 |
|------|------|
| `Ctrl+=` | 透過度を上げる (不透明に) |
| `Ctrl+-` | 透過度を下げる (透明に) |
| `Ctrl+0` | 透過度をデフォルト (75%) にリセット |

### フォントサイズ

| 操作 | 方法 |
|------|------|
| 拡大 | `Ctrl+マウスホイール上` |
| 縮小 | `Ctrl+マウスホイール下` |

> `Ctrl+=/-/0` は透過度に割り当て済みのため、フォントサイズはマウスホイールで操作する。

### その他のデフォルトキーバインド

| キー | 操作 |
|------|------|
| `Ctrl+Shift+C` | コピー |
| `Ctrl+Shift+V` | ペースト |
| `Ctrl+Shift+F` | 検索 |
| `Ctrl+Shift+P` | コマンドパレット |
| `Ctrl+Shift+X` | コピーモードに入る |
| `F11` | フルスクリーン |

## コピーモード

`Ctrl+Shift+X` または `<Leader>y` でコピーモードに入る。Vim ライクにテキストを選択してコピーできる。

### コピーモード内の操作

| キー | 操作 |
|------|------|
| `h/j/k/l` | カーソル移動 |
| `w/b/e` | 単語単位の移動 |
| `0` / `$` | 行頭/行末 |
| `v` | 選択開始 |
| `V` | 行選択 |
| `y` | 選択範囲をコピーしてコピーモード終了 |
| `q` | QuickSelect (URL やパスなどを自動ハイライトして選択) |
| `Escape` | コピーモード終了 |

**QuickSelect** (`q`): 画面上の URL、ファイルパス、ハッシュなどをハイライトし、ラベル文字を打つだけでコピーできる。ログから URL を拾うときに便利。

## smart-splits (Neovim 連携)

wezterm のペインと Neovim のウィンドウをシームレスに行き来できる。

```
┌──── wezterm ペイン ────┬──── wezterm ペイン ────┐
│  ┌─ nvim split ──┐     │                        │
│  │               │     │   bash                  │
│  │  Ctrl+l ──────│─────│──→ ここに移動           │
│  │               │     │                        │
│  └───────────────┘     │                        │
└────────────────────────┴────────────────────────┘
```

- `Ctrl+h/j/k/l` — Neovim ウィンドウ → wezterm ペイン をまたいで移動
- `Alt+h/j/k/l` — Neovim ウィンドウ / wezterm ペイン をまたいでリサイズ

Neovim 側にも smart-splits プラグインが入っており、双方向にシームレスに機能する。

## ワークフロー

### プロジェクトごとにワークスペースを分ける

```
1. <Leader>c でタブを必要数作成 (エディタ用、テスト用、サーバー用など)
2. <Leader>R でワークスペース名を "my-project" に変更
3. 別プロジェクトに移るとき:
   <Leader>W でワークスペース一覧 → 新規作成 or 切替
```

### Neovim + ターミナルの並列作業

```
1. <Leader>v で垂直分割
2. 左ペインで nvim、右ペインでテスト実行やサーバー起動
3. Ctrl+h/l で瞬時にペイン間移動
4. Ctrl+Shift+Z で一時的にペインをズーム (全画面化)
```

### ログから URL をコピー

```
1. Ctrl+Shift+X でコピーモードに入る
2. q で QuickSelect
3. ハイライトされた URL のラベル文字を打つ → クリップボードにコピー
```
