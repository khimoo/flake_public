# yazi — TUI ファイルマネージャ

ターミナル内で動作するファイルマネージャ。Vim ライクな操作体系 + プラグインによる拡張。

> 設定: `modules/home-manager/yazi.nix`

## 起動方法

```bash
yy        # yazi を起動し、終了時にいたディレクトリへ cd する (推奨)
yazi      # yazi を起動する (終了後も元のディレクトリのまま)
```

`yy` は `enableBashIntegration` により自動定義される関数。ファイルブラウズ後にそのディレクトリで作業を続けたい場合は必ず `yy` を使う。

## 画面構成

```
┌─────────────┬──────────────────┬──────────────┐
│  親ディレクトリ │   現在のディレクトリ   │  プレビュー    │
│  (parent)    │   (current)       │  (preview)   │
│              │   > file1.rs      │  (内容表示)   │
│              │     file2.rs      │              │
│              │     src/          │              │
└─────────────┴──────────────────┴──────────────┘
```

3 カラムレイアウト。カーソル位置のファイルが右カラムにプレビューされる。

## 基本操作

### ナビゲーション

| キー | 操作 |
|------|------|
| `h` | 親ディレクトリに戻る |
| `l` / `Enter` | ディレクトリに入る / ファイルを開く (smart-enter) |
| `j` / `k` | カーソルを下/上に移動 |
| `G` | 末尾に移動 |
| `gg` | 先頭に移動 |
| `f` | ファイル名の先頭文字でジャンプ (jump-to-char) |

### 検索・フィルタ

| キー | 操作 |
|------|------|
| `F` | インクリメンタルフィルタ (smart-filter) |
| `/` | 検索 (正規表現) |
| `n` / `N` | 次/前の検索結果 |

**smart-filter のコツ**: 入力中にリアルタイムで絞り込まれ、候補が 1 つになると自動でそのファイル/ディレクトリに入る。ディレクトリ名の一部をタイプするだけで高速に移動できる。

### ファイル操作

| キー | 操作 |
|------|------|
| `Space` | ファイルを選択/選択解除 |
| `y` | 選択ファイルをヤンク (コピー用にマーク) |
| `x` | 選択ファイルをカット |
| `p` | ペースト (ヤンク/カットしたファイルを移動/コピー) |
| `d` | 選択ファイルを削除 (ゴミ箱へ) |
| `D` | 選択ファイルを完全削除 |
| `a` | 新規ファイル作成 (`/` で終わるとディレクトリ) |
| `r` | リネーム |
| `cm` | パーミッション変更 (chmod プラグイン) |
| `.` | 隠しファイルの表示/非表示切替 |

### タブ

| キー | 操作 |
|------|------|
| `t` | 新しいタブを開く |
| `1`~`9` | タブ切替 |
| `[` / `]` | 前/次のタブ |
| `{` / `}` | タブの入れ替え |

### シェル連携

| キー | 操作 |
|------|------|
| `s` | search |
| `S` | 上側でsearch |
| `q` | yazi を終了 |

## プラグイン

### smart-enter

`Enter` キーの動作をコンテキストに応じて切り替える。

- ディレクトリ → そのディレクトリに入る
- ファイル → デフォルトアプリで開く

### smart-filter (`F`)

インクリメンタルフィルタ。標準の検索 (`/`) と異なり:

- 入力に応じてリアルタイムで表示をフィルタリング
- 候補が 1 つに絞られると自動でそのアイテムに入る
- 深いディレクトリ階層を素早く掘り進められる

### jump-to-char (`f`)

Vim の `f` と同じ感覚で、ファイル名の先頭文字を指定してジャンプ。大量のファイルがあるディレクトリで `j`/`k` の連打を避けられる。

### chmod (`cm`)

選択したファイルのパーミッションを変更する UI を表示。rwx のトグルで操作する。

### git

ファイル一覧の linemode に Git の変更状態を表示。

- `M` — Modified
- `A` — Added (ステージ済み)
- `?` — Untracked

### full-border

yazi 全体に枠線を表示し、3 カラムの境界を明確にする。

## ワークフロー

### ファイルの移動・コピー

```
1. 移動元で Space でファイルを選択 (複数可)
2. x (カット) または y (コピー)
3. 移動先ディレクトリに移動
4. p でペースト
```

### 一括リネーム

```
1. 対象ファイルを Space/V で選択
2. r でバルクリネーム → $EDITOR が開く
3. ファイル名を編集して保存
```

### ディレクトリの高速移動

```
F → "src" とタイプ → 自動で src/ に入る
F → "main" とタイプ → main.rs にフォーカス → Enter で開く
```

`smart-filter` を連打することで、`src/app/components/Button.tsx` のような深い階層に数秒で到達できる。
