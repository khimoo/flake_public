# 編集補助機能

コメントアウト、囲み文字の操作、数値・真偽値の増減、検索マッチ位置の可視化、Undo 履歴のツリー管理、インデントの自動判定機能。

設定: `lua/plugins/` 配下の `comment.lua`、`surround.lua`、`dial.lua`、`hlslens.lua`、`undotree.lua`

## コメント機能（Comment.nvim）

| キー | モード | 機能 |
|------|--------|------|
| `gcc` | n | カレント行をコメントアウト / 解除 |
| `gc` + motion | n | 指定範囲を行コメントにする（例: `gcip` で段落、`gc5j` で 5 行） |
| `gbc` | n | カレント行をブロックコメント（`/* ... */`）にする / 解除 |
| `gb` + motion | n | 指定範囲をブロックコメントにする |
| `gc` / `gb` | v | 選択範囲を行 / ブロックコメントにする |
| `gcO` / `gco` | n | 現在行の上 / 下にコメント行を挿入する |
| `gcA` | n | 行末にコメントを追加する |

## 囲み文字の操作（nvim-surround）

キーマッピングは `<leader>s` 配下に割り当てられている。

| キー | 機能 | 例 |
|------|------|----|
| `<leader>sys` + motion + 記号 | 囲みを追加する | `<leader>sysiw"` で `word` を `"word"` に囲む |
| `<leader>scs` + 変更前の記号 + 変更後の記号 | 囲み文字を変更する | `<leader>scs"'` で `"x"` を `'x'` に変更する |
| `<leader>sds` + 記号 | 囲み文字を削除する | `<leader>sds"` で `"x"` を `x` に戻す |
| `<leader>syss` + 記号 | 行全体を囲む | `<leader>syss)` で現在行を `(...)` で囲む |
| `<leader>sS` + 記号 | ビジュアルモードの選択範囲を囲む | |
| `<leader>sgS` + 記号 | 行単位の選択範囲を行全体で囲む | |
| `<C-g>s` + 記号 | 挿入モード中に囲み文字を挿入する | |

囲み記号には `"`、`'`、`` ` ``、`(`、`[`、`{`、`<`、`t`（HTML タグ）などが利用できる。

## 数値・値の増減（dial.nvim）

数値だけでなく、`true` / `false` などの真偽値や日付もインクリメント / デクリメントできる。

| キー | モード | 機能 |
|------|--------|------|
| `<C-a>` / `<C-x>` | n, v | 値を増やす / 減らす |
| `g<C-a>` / `g<C-x>` | n, v | 連番にして増やす / 減らす |

## 検索マッチ表示（hlslens）

検索実行時、マッチ総数と現在のマッチ位置を行の横にバーチャルテキストで表示する。

| キー | 機能 |
|------|------|
| `n` / `N` | 次 / 前のマッチ箇所へ移動する |
| `*` / `#` | カーソル下の単語を前方 / 後方に検索する |
| `g*` / `g#` | カーソル下の単語を部分一致で検索する |
| `<Esc><Esc>` | 検索ハイライトを消去する |

## Undo 履歴管理（undotree）

`<leader>u` で Undo 履歴をツリー形式で表示する。枝分かれした過去の変更履歴にも自在に戻ることができる。

## インデントの自動判定（guess-indent.nvim）

ファイルを開いた際、タブ / スペースの種類やインデント幅をファイル内容から自動的に推測してバッファに設定する。
