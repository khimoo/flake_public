# テスト実行（neotest）

カーソル位置のテスト実行、実行結果の確認、DAP によるテストのデバッグ実行を行います。Rust の場合は neotest-rust を介して `cargo test` が実行されます。

設定ファイル: `lua/plugins/neotest.lua`

## キーマップ

| キー | 機能 |
|------|------|
| `<leader>tt` | カーソル位置に最も近いテストを実行 |
| `<leader>tf` | 現在のファイル内の全テストを実行 |
| `<leader>tl` | 直前に実行したテストを再実行 |
| `<leader>ts` | テスト一覧パネルの表示 / 非表示を切り替え |
| `<leader>to` | テスト出力をフローティングウィンドウで表示 |
| `<leader>tO` | テスト出力パネルの表示 / 非表示を切り替え |
| `<leader>tS` | 実行中のテストを停止 |
| `<leader>td` | カーソル位置に最も近いテストを DAP でデバッグ実行 |

Rust では内部で `cargo test` を使用するため、初回の実行にはコンパイル時間がかかります。なお、`<leader>td` によるデバッグには rustaceanvim と同様に codelldb が使用されます。

## テストの流れ

```
（テストコードを書く）
<leader>tt  → カーソル下のテストを実行（テストが失敗することを確認）
（実装コードを書く）
<leader>tl  → テストがパスするまで前回のテストを再実行
<leader>tf  → ファイル全体のテストを実行し、既存のテストが壊れていないか確認
```

テストコードをデバッグする際は、`<leader>db` でブレークポイントを設置してから `<leader>td` を実行してください。
