# Git

gitsigns で行番号の横に変更ステータスを表示し、変更箇所（hunk）ごとの操作を行います。diffview では指定したリビジョン間の差分を専用タブで閲覧できます。

設定ファイル: `lua/plugins/git.lua`

## 差分を開く（diffview）

リビジョン指定にはブランチ名やタグ名をそのまま利用できます。引数は `<Tab>` で補完可能です。

| コマンド | 用途 |
|----------|------|
| `:DiffviewOpen` | ワーキングツリーと HEAD の差分を表示 |
| `:DiffviewOpen A..B` | リビジョン A と B の差分を表示 |
| `:DiffviewFileHistory` | 現在のファイルの変更履歴を表示 |
| `:DiffviewFileHistory --range=A..B` | A..B に含まれるコミット履歴を 1 つずつ確認 |
| `:DiffviewClose` | diffview を閉じる |

## gitsigns のキーマップ

Git リポジトリ内であれば、LSP サーバーが起動していなくても利用できます。

### ナビゲーション

| キー | 機能 |
|------|------|
| `]c` | 次の変更箇所 (hunk) に移動 |
| `[c` | 前の変更箇所 (hunk) に移動 |

※ diff モード中は Vim 標準の `]c` / `[c` として動作します。

### hunk 操作

| キー | モード | 機能 |
|------|--------|------|
| `<leader>gs` | n | カーソル下の hunk をステージ |
| `<leader>gr` | n | カーソル下の hunk をリセット (変更破棄) |
| `<leader>gs` | v | 選択範囲をステージ |
| `<leader>gr` | v | 選択範囲をリセット |
| `<leader>gS` | n | バッファ全体の変更をステージ |
| `<leader>gR` | n | バッファ全体の変更をリセット |

### プレビュー

| キー | 機能 |
|------|------|
| `<leader>gp` | hunk のポップアッププレビュー |
| `<leader>gi` | hunk のインラインプレビュー |

### blame / diff

| キー | 機能 |
|------|------|
| `<leader>gb` | カーソル行の blame 表示 (変更者・日時の確認) |
| `<leader>gd` | HEAD との差分表示 |
| `<leader>gD` | 直前コミット (`~`) との差分表示 |

### quickfix

| キー | 機能 |
|------|------|
| `<leader>gq` | 現在のバッファの変更箇所を quickfix に送る |
| `<leader>gQ` | 全バッファの変更箇所を quickfix に送る |

### トグル

| キー | 機能 |
|------|------|
| `<leader>gtb` | カーソル行の blame 表示の ON/OFF |
| `<leader>gtd` | 削除行の表示 ON/OFF |
| `<leader>gtw` | 単語単位の差分 (word diff) 表示の ON/OFF |

### テキストオブジェクト

| キー | モード | 機能 |
|------|--------|------|
| `ih` | o, x | hunk を選択（`dih` で hunk 削除、`yih` で hunk ヤンク） |

## diffview のキーマップ

diffview のデフォルトキーマップです。パネルの種類によって割り当てが異なります。`g?` でコンテキストに応じたヘルプが開くため、ここでは頻出の操作のみを掲載します。

### 共通操作 (ファイルパネル / ファイル履歴パネル)

| キー | 機能 |
|------|------|
| `<CR>` / `o` / `l` | カーソル位置のファイルの diff を開く |
| `j` / `k` | エントリ間を移動 |
| `<Tab>` / `<S-Tab>` | 次 / 前のファイルの diff を開く |
| `[F` / `]F` | 最初 / 最後のファイルに移動 |
| `gf` | 元のタブページで対象ファイルを開く |
| `<leader>e` | ファイルパネルにフォーカス |
| `<leader>b` | ファイルパネルの表示 / 非表示を切り替え |
| `g<C-x>` | レイアウトの切り替え |
| `g?` | ヘルプを表示 |

### ファイルパネル (`:DiffviewOpen`)

| キー | 機能 |
|------|------|
| `-` / `s` | ファイルをステージ / アンステージ |
| `S` | 全ファイルをステージ |
| `U` | 全ファイルをアンステージ |
| `X` | 変更を破棄して左側（ベース）の状態に戻す |
| `L` | コミットログを表示 |
| `i` | リスト表示とツリー表示を切り替え |
| `R` | ファイル一覧を再読み込み |

### ファイル履歴パネル (`:DiffviewFileHistory`)

| キー | 機能 |
|------|------|
| `<CR>` | 選択したコミットの変更ファイル一覧を開く |
| `<C-A-d>` | 選択したコミットを新しい diffview タブで開く |
| `L` | コミットメッセージの全文を表示 |
| `y` | コミットハッシュをクリップボードにコピー |
| `X` | そのコミット時点の状態にファイルを復原 |
| `g!` | オプションパネルを開く (`--follow` や `diff_merges` の切り替え) |

### マージコンフリクトの解決時

| キー | 機能 |
|------|------|
| `]x` / `[x` | 次 / 前のコンフリクト箇所にジャンプ |
| `<leader>co` / `<leader>ct` / `<leader>cb` | ours（自分側）/ theirs（相手側）/ base（共通祖先）を採用 |
| `<leader>ca` | 全ての変更を残す |
| `dx` | コンフリクト箇所を削除 |

※ `<leader>c` 系のコマンドは大文字（例: `<leader>cO`）にすることで、ファイル全体に一括適用できます。

## 変更を hunk ごとにステージする

```
]c          → hunk を巡回
<leader>gp  → 変更内容を確認
<leader>gs  → 問題なければステージ
<leader>gr  → 不要な変更ならリセット
```

## ブランチ間の差分を確認する

```
:DiffviewOpen main..feature   → 2つのブランチ全体の差分を表示
<CR>                          → ファイルを選択して差分を確認
<Tab>                         → 次のファイルへ移動
:DiffviewClose                → diffview を終了
```

段階的に積み上げたブランチ列（A→B→C）をレビューする場合は、隣接するペア（A..B、B..C）を順に指定します。

## コミット履歴を1つずつ追う

```
:DiffviewFileHistory --range=main..feature
<CR>        → コミットを選択すると、そのコミット単体の変更ファイル一覧を表示
L           → コミットメッセージを確認
<C-A-d>     → そのコミットを個別のタブで開いて詳細を確認
```

※ `<C-A-d>` の比較対象は常に親コミットです。離れたコミット同士を比較したい場合は、`y` でコミットハッシュをコピーし、`:DiffviewOpen <hash1>..<hash2>` を実行してください。

## コミット前の変更を確認・整理する

```
:DiffviewOpen   → ワーキングツリーと HEAD の差分を表示
<CR>            → ファイルごとに変更を確認
-               → ファイル単位でステージング
```

hunk 単位で細かく選んでステージングしたい場合は、gitsigns 側（`<leader>gs`）を利用します。
