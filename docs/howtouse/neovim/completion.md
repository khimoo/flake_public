# 補完（blink.cmp）

LSP、ファイルパス、スニペット、バッファ内の単語を補完候補として表示する。候補は LSP、パス、スニペット、バッファ内単語の優先順で並ぶ。コマンドラインでも補完が利用できる。

設定: `lua/plugins/cmp.lua`

## 挿入モードのキー操作

| キー | 機能 |
|------|------|
| `<C-space>` | 補完メニューを開く / ドキュメント表示の切り替え |
| `<C-n>` / `<C-p>` | 次 / 前の候補を選択 |
| `<C-y>` | 候補を確定する |
| `<C-CR>` | 候補を確定する（Kitty キーボードプロトコル対応端末のみ。[cheatsheet.md](./cheatsheet.md#対応端末でのみ届くキー) を参照） |
| `<C-e>` | 補完メニューを閉じる |
| `<C-b>` / `<C-f>` | ドキュメントをスクロールする |
| `<C-k>` | シグネチャヘルプの表示 / 非表示を切り替える |
| `<Tab>` / `<S-Tab>` | スニペットの次 / 前のプレースホルダーへ移動する |

## コマンドラインのキー操作

| キー | 機能 |
|------|------|
| `<Tab>` / `<S-Tab>` | 次 / 前の候補を選択 |
| `<C-y>` | 候補を確定する |
| `<C-e>` | 補完メニューを閉じる |

## 補完候補が表示されない場合

- `<C-space>` を押して手動で補完メニューを開く。
- バッファ内単語の候補は、2 文字以上入力すると表示される。
- LSP の候補が出ない場合は、`:checkhealth vim.lsp` を実行して LSP サーバーが正常に接続されているか確認する。
- SKK が有効な間は補完機能が無効化される。SKK をオフにすると通常の補完に戻る。
