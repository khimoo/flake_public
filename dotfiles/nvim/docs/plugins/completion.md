# 補完 (blink.cmp)

高速な補完エンジン。nvim-cmp の後継的な位置づけ。

- 設定ファイル: `lua/plugins/cmp.lua`

## プラグイン

### blink.cmp

デフォルト設定で使用中。ソースは LSP、パス、スニペット、バッファの4つ。

## キーバインド (デフォルト)

| キー | 機能 |
|------|------|
| `<C-space>` | 補完を手動で開く |
| `<C-n>` | 次の候補 |
| `<C-p>` | 前の候補 |
| `<CR>` | 候補を確定 |
| `<C-e>` | 補完をキャンセル |
| `<Tab>` | スニペットの次のプレースホルダに移動 |
| `<S-Tab>` | スニペットの前のプレースホルダに移動 |

## 備考

- skkeleton (日本語入力) が有効になると blink.cmp は自動で無効化される (`skkeleton-enable-pre` で `vim.b.completion = false`)
- skkeleton が無効になると自動で再有効化される
