# Treesitter 関連

構文解析ベースのハイライト、テキストオブジェクト、コード整形。

- 設定ファイル: `lua/plugins/treesitter.lua`

## プラグイン

### nvim-treesitter

構文解析エンジン。`highlight = { enable = true }` でシンタックスハイライトを treesitter ベースに置き換えている。

### treesj

1行↔複数行のトグル。引数リストやテーブルを展開/折りたたみ。

| キー | 機能 |
|------|------|
| `<leader>m` | 1行と複数行をトグル |

例:
```
-- <leader>m で切り替え
local t = { a = 1, b = 2, c = 3 }
-- ↕
local t = {
  a = 1,
  b = 2,
  c = 3,
}
```

### nvim-treesitter-textsubjects

treesitter の構文木に基づいたスマートなテキスト選択。ビジュアルモードで使う。

| キー | 機能 | 説明 |
|------|------|------|
| `.` | スマート選択 | 押すたびに選択範囲が構文的に広がる |
| `;` | コンテナ外側 | 関数・ブロック等の外側を選択 |
| `i;` | コンテナ内側 | 関数・ブロック等の内側を選択 |
| `,` | 前の選択に戻る | |

例: `v` でビジュアルモード → `.` を連打すると 変数 → 式 → 文 → 関数本体 → 関数全体 と広がる。

### aerial.nvim

コードのアウトライン (関数・型の一覧) をサイドパネルに表示。

| キー | 機能 |
|------|------|
| `<leader>o` | アウトラインの表示/非表示トグル |
| `[s` | 前のシンボルにジャンプ |
| `]s` | 次のシンボルにジャンプ |

`[s`/`]s` は `[d`/`]d` (診断ジャンプ) と対になる覚え方。
