# render-markdown.nvim — Markdown バッファ内プレビュー

Markdown ファイルを開くとバッファ内で装飾表示される。ブラウザ不要。

> 設定: `dotfiles/nvim/lua/plugins/render-markdown.lua`

## 動作

- **ノーマルモード**: 装飾表示 (見出し背景色、テーブル罫線、アイコン等)
- **挿入モード**: 生の Markdown テキストに戻る (編集を邪魔しない)

Markdown ファイル (`*.md`) を開くだけで自動的に有効になる。

## 装飾される要素

| 要素 | 装飾 |
|------|------|
| `# 見出し` | レベルに応じた背景色 + アイコン |
| テーブル | Unicode 罫線で整形表示 |
| `- [x]` チェックボックス | アイコン化 |
| コードブロック | 背景色 + 言語ラベル |
| `[link](url)` | リンクアイコン |
| `**太字**`, `*斜体*` | フォント装飾 |
| `---` 水平線 | 全幅の罫線 |
| `> 引用` | 左ボーダー + 背景色 |

## コマンド

| コマンド | 操作 |
|---------|------|
| `:RenderMarkdown toggle` | 装飾表示の ON/OFF 切替 |
| `:RenderMarkdown enable` | 装飾表示を有効化 |
| `:RenderMarkdown disable` | 装飾表示を無効化 |
