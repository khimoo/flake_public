# ナビゲーション (バッファ・ウィンドウ管理)

バッファのタブ表示とウィンドウリサイズ。

- 設定ファイル: `lua/plugins/tab.lua`

## プラグイン

### barbar.nvim

バッファをタブバーとして表示。

### winresizer

`<C-Q>` でウィンドウリサイズモードに入り、hjkl でサイズ変更。

## キーバインド

### バッファ移動

| キー | 機能 |
|------|------|
| `gt` | 次のバッファ |
| `gT` | 前のバッファ |
| `<A-1>` 〜 `<A-9>` | バッファ番号で直接移動 |
| `<A-0>` | 最後のバッファ |
| `<C-p>` | バッファピック (1文字で選べるモード) |

### バッファ操作

| キー | 機能 |
|------|------|
| `<C-w>c` | バッファを閉じる |
| `<A-p>` | バッファをピン留め |
| `<C-S-p>` | バッファピックで削除 |
| `<A-<>` | バッファを左に移動 |
| `<A->>` | バッファを右に移動 |

### バッファのソート

| キー | 機能 |
|------|------|
| `<leader>bb` | バッファ番号順 |
| `<leader>bn` | 名前順 |
| `<leader>bd` | ディレクトリ順 |
| `<leader>bl` | 言語順 |
| `<leader>bw` | ウィンドウ番号順 |

### ウィンドウリサイズ

| キー | 機能 |
|------|------|
| `<C-Q>` | winresizer モード開始 |
| (モード中) `h`/`j`/`k`/`l` | ウィンドウサイズ変更 |
| (モード中) `<CR>` or `<Esc>` | モード終了 |

## バッファ vs タブ vs ウィンドウ

- **バッファ**: 開いているファイル。barbar のタブバーに表示される
- **ウィンドウ**: バッファの表示領域。`:split`, `:vsplit` で分割
- **タブページ**: ウィンドウのレイアウトを保存する単位。あまり使わない

barbar で見えているのはバッファ。`gt`/`gT` や `<A-数字>` でバッファ間を移動する。
