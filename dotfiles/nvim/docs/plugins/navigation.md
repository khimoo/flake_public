# ナビゲーション (バッファ・ウィンドウ・ペイン管理)

ファイル間の高速移動と、Neovim ウィンドウ / wezterm ペインの統合操作。

- 設定ファイル: `lua/plugins/harpoon.lua`, `lua/plugins/smart-splits.lua`

## プラグイン

### harpoon2

よく使うファイルをマークして素早く切り替える。バッファリストではなく「お気に入りリスト」方式。

### smart-splits.nvim

Neovim のウィンドウと wezterm のペインをシームレスに操作する。
詳細は [smart-splits.md](./smart-splits.md) を参照。

## キーバインド

### ファイルマーク (harpoon)

| キー | 機能 |
|------|------|
| `<leader>ha` | 現在のファイルをリストに追加 |
| `<leader>hh` | harpoon メニューを開く |
| `<leader>h1` 〜 `<leader>h5` | マークしたファイルに直接移動 |
| `gt` | リスト内の次のファイル |
| `gT` | リスト内の前のファイル |

### ウィンドウ/ペイン移動 (smart-splits)

| キー | 機能 |
|------|------|
| `Ctrl+h` | 左のウィンドウ/ペインに移動 |
| `Ctrl+j` | 下のウィンドウ/ペインに移動 |
| `Ctrl+k` | 上のウィンドウ/ペインに移動 |
| `Ctrl+l` | 右のウィンドウ/ペインに移動 |

### ウィンドウ/ペインリサイズ (smart-splits)

| キー | 機能 |
|------|------|
| `Alt+h` | 左方向にリサイズ |
| `Alt+j` | 下方向にリサイズ |
| `Alt+k` | 上方向にリサイズ |
| `Alt+l` | 右方向にリサイズ |

### バッファスワップ (smart-splits, Neovim 内のみ)

| キー | 機能 |
|------|------|
| `<leader><leader>h` | 左のウィンドウとバッファを交換 |
| `<leader><leader>j` | 下のウィンドウとバッファを交換 |
| `<leader><leader>k` | 上のウィンドウとバッファを交換 |
| `<leader><leader>l` | 右のウィンドウとバッファを交換 |

## ファイル間移動の使い分け

- **harpoon** (`<leader>ha` / `gt`/`gT`): 作業中に頻繁に行き来するファイル（実装とテスト、型定義と実装など）
- **telescope** (`<leader>ff`): ファイル名で検索して開く（初めてのファイルや名前がわかっている場合）
- **oil** (`<leader>fe`): ディレクトリ構造を見ながら探す
- **LSP** (`gd` / `grr`): 定義やリファレンスに飛ぶ
