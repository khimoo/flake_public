# 編集支援プラグイン

コメント、囲み操作、インクリメント、検索ハイライト、undo ツリー。

- 設定ファイル: `lua/plugins/comment.lua`, `lua/plugins/others.lua`

## Comment.nvim

コメントの ON/OFF をトグル。

| キー | モード | 機能 | 例 |
|------|--------|------|----|
| `gcc` | n | 行コメントトグル | 現在行をコメント/アンコメント |
| `gc` + motion | n | 行コメント (operator) | `gcip` で段落、`gc5j` で5行 |
| `gbc` | n | ブロックコメントトグル | `/* ... */` 形式 |
| `gb` + motion | n | ブロックコメント (operator) | |
| `gc` | v | 選択範囲を行コメント | |
| `gb` | v | 選択範囲をブロックコメント | |
| `gcO` | n | 上にコメント行を挿入 | |
| `gco` | n | 下にコメント行を挿入 | |
| `gcA` | n | 行末にコメントを追加 | |

## nvim-surround

テキストの囲み (引用符、括弧等) の追加・変更・削除。

**注意**: 現在 `<leader>s` プレフィックス付きにカスタマイズされている。

| キー | 機能 | 例 |
|------|------|----|
| `<leader>sys` + motion + 記号 | 囲みを追加 | `<leader>sysiw"` → `word` を `"word"` に |
| `<leader>scs` + 旧 + 新 | 囲みを変更 | `<leader>scs"'` → `"x"` を `'x'` に |
| `<leader>sds` + 記号 | 囲みを削除 | `<leader>sds"` → `"x"` を `x` に |
| `<leader>syss` + 記号 | 行全体を囲む | `<leader>syss)` → 行を `(...)` で囲む |

使える記号: `"`, `'`, `` ` ``, `(`, `[`, `{`, `<`, `t` (HTML タグ) 等。

## dial.nvim

`<C-a>`/`<C-x>` のインクリメント/デクリメントを拡張。数値だけでなく bool 等も対応。

| キー | モード | 機能 |
|------|--------|------|
| `<C-a>` | n | インクリメント |
| `<C-x>` | n | デクリメント |
| `g<C-a>` | n, v | 連番インクリメント |
| `g<C-x>` | n, v | 連番デクリメント |
| `<C-a>` | v | ビジュアル選択内でインクリメント |
| `<C-x>` | v | ビジュアル選択内でデクリメント |

対応する値: 数値、`true`/`false`、日付 等。

## hlslens

検索時にマッチ数と現在位置を仮想テキストで表示。

| キー | 機能 |
|------|------|
| `n` / `N` | 次/前のマッチ (hlslens 連携済み) |
| `*` / `#` | カーソル下の単語を前方/後方検索 |
| `g*` / `g#` | 部分一致で検索 |
| `<Esc><Esc>` | 検索ハイライト解除 |

## undotree

undo 履歴をツリー形式で可視化。分岐した undo 履歴にもアクセスできる。

| キー | 機能 |
|------|------|
| `<leader>u` | undotree の表示/非表示トグル |

## nvim-bqf

quickfix ウィンドウの強化。プレビュー表示やファジー検索が追加される。
キーバインドはデフォルト (quickfix ウィンドウ内で `<CR>` で開く等)。

## guess-indent.nvim

ファイルを開いた際にインデント設定 (タブ/スペース、幅) を自動検出する。
設定不要。
