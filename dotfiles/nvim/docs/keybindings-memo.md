# キーバインドつかいこなせてないやつメモ

設定を見直して修正した記録と、覚えるべき操作のメモ。

## 変更履歴 (2026-05-04)

### 1. Telescope 検索系キーマップ追加

変更前は `<leader>t` (コマンド一覧) と `<leader>f` (file_browser) のみだった。
Telescope の本領は**ファジー検索**なので、主要な検索系を `<leader>f` 配下に統一した。

→ 詳細: [plugins/telescope.md](./plugins/telescope.md)

### 2. LSP キーマップ: 頻出操作のプレフィックス撤廃

変更前は全て `<leader>l` プレフィックス付きだった (例: `<leader>lgd`)。
`gd`, `gr`, `K` 等の頻出操作をプレフィックスなしに変更し、2キーストローク削減した。

→ 詳細: [plugins/lsp.md](./plugins/lsp.md)

### 3. `y` (yank) の標準動作を復元

変更前は `y` が無効化され `yy` でしかヤンクできなかった。
標準の `y` + motion を復元。

#### 覚えるべき y の使い方

| キー | 動作 | 説明 |
|------|------|------|
| `yy` | 行ヤンク | 現在行をコピー |
| `yiw` | 単語全体ヤンク | カーソル位置の単語全体 |
| `yi"` | 引用符内ヤンク | `"..."` の中身をコピー |
| `yi(` / `yi{` | 括弧���ヤンク | 括弧の中身をコピー |
| `yap` | 段落ヤンク | 段落全体をコピ�� |
| `y$` / `y0` | 行末/行頭まで | カーソルから行末/行頭まで |

**パターン**: `y` + テキストオブジェクト。`d` (削除) や `c` (変更) も同じ文法。

### 4. aerial のシンボルジャンプキーを変更

`{`/`}` を Vim 標準の段落移動に戻し、aerial は `[s`/`]s` に��更。

→ 詳細: [plugins/treesitter.md](./plugins/treesitter.md)

変更前は `<leader>ccc` (行コメント), `<leader>cc` (operator) 等に変更されていた。
`gcc`/`gc` はデファクトスタンダードなのでデフォルトに戻��た。
