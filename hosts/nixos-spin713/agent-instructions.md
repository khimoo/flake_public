# このマシン（nixos-spin713）

非力なマシン（4 スレッド、メモリ 7.6 GiB、Intel 内蔵 GPU）。

- メモリを多く使う処理と GPU が要る処理は、まずデスクトップ（`ssh desktop-ts`、AMD GPU）で実行できるか確かめ、できればそこで実行する。作業ツリーはデスクトップの `/tmp` にコピーして使う。
- デスクトップで実行できないときは、処理のピークメモリと CPU 負荷を概算し、`free -m` の空きと比べてこのマシンがフリーズしないと判断できたときだけ手元で実行する。判断できなければ実行せず、人間に確認する。
- Nix は `max-jobs = 0` で手元ではビルドしない。手元でビルドするときは、上の判断を経てから `--max-jobs` を渡す。
