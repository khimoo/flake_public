# 補完 (blink.cmp)

設定: `lua/plugins/cmp.lua`

## 機能

| 機能 | 説明 |
|------|------|
| LSP 補完 | 関数名・型名・変数名などを LSP から取得 |
| パス補完 | ファイルパスを `/` や `./` 入力時に補完 |
| バッファ補完 | 現在のバッファ内の単語を補完候補に含める |
| スニペット | 定型パターンの展開（`fn` → 関数テンプレート等） |
| シグネチャヘルプ | 関数の引数入力中に、今どの引数を入力しているか表示 |
| ゴーストテキスト | 補完候補がカーソル位置に薄く表示される |
| ドキュメント自動表示 | 候補選択時にドキュメントが自動でポップアップ |
| コマンドライン補完 | `:` コマンドラインでもパスやコマンドを補完 |

## キーバインド

### 挿入モード（補完メニュー）

| キー | 機能 |
|------|------|
| `<C-space>` | 補完を手動で開く / ドキュメント表示トグル |
| `<C-n>` | 次の候補 |
| `<C-p>` | 前の候補 |
| `<C-y>` | 候補を確定 |
| `<C-CR>` | 候補を確定（kitty keyboard protocol 対応端末のみ。非対応なら `<C-y>`） |
| `<C-e>` | 補完をキャンセル |
| `<C-b>` / `<C-f>` | ドキュメントをスクロール |
| `<C-k>` | シグネチャヘルプの表示/非表示 |
| `<Tab>` | スニペットの次のプレースホルダに移動 |
| `<S-Tab>` | スニペットの前のプレースホルダに移動 |

### コマンドライン（`:` モード）

| キー | 機能 |
|------|------|
| `<Tab>` | 次の候補 |
| `<S-Tab>` | 前の候補 |
| `<C-y>` | 候補を確定 |
| `<C-e>` | 補完をキャンセル |

## 補完が出ないとき


```
- <C-space> で手動トリガー（自動補完が発火しなかった場合）
- LSP が起動しているか確認: :LspInfo または :checkhealth lsp
- バッファ補完は最低2文字入力で発火する
```

## skkeleton との連携

- skkeleton (日本語入力) が有効になると blink.cmp は自動で無効化される
  (`skkeleton-enable-pre` で `vim.b.completion = false`)
- skkeleton が無効になると自動で再有効化される
- 日本語入力中に補完メニューが出て邪魔になることはない

## 補完ソースの優先度

候補の表示順は以下の優先度で並ぶ:

1. **lsp** — LSP からの候補（最も精度が高い）
2. **path** — ファイルパス
3. **snippets** — スニペット
4. **buffer** — バッファ内の単語（フォールバック）
