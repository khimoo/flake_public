# Git 連携

変更の可視化、hunk 操作、diff 表示。

- 設定ファイル: `lua/plugins/git.lua`

## プラグイン

### gitsigns.nvim

行番号横に変更状態を表示し、hunk 単位での操作を提供する。

### diffview.nvim

リビジョン範囲を受け取り、タブページで差分を表示する。ブランチ名・タグ名をそのまま渡せるので、コミットハッシュを調べる必要はない。引数は `<Tab>` で補完が効く。

| コマンド | 用途 |
|----------|------|
| `:DiffviewOpen` | 作業ツリーと HEAD の差分 |
| `:DiffviewOpen A..B` | リビジョン A と B の差分 |
| `:DiffviewFileHistory` | 現在のファイルの変更履歴 |
| `:DiffviewFileHistory --range=A..B` | A..B に含まれるコミットを1つずつ |
| `:DiffviewClose` | 閉じる |

## キーバインド (gitsigns)

全て `<leader>g` 配下。LSP がなくても Git リポジトリ内なら動作する。

### ナビゲーション

| キー | 機能 |
|------|------|
| `]c` | 次の変更箇所 (hunk) にジャンプ |
| `[c` | 前の変更箇所 (hunk) にジャンプ |

diff モード中は Vim 標準の `]c`/`[c` として動作する。

### hunk 操作

| キー | モード | 機能 |
|------|--------|------|
| `<leader>gs` | n | hunk をステージ |
| `<leader>gr` | n | hunk をリセット (変更取消) |
| `<leader>gs` | v | 選択範囲をステージ |
| `<leader>gr` | v | 選択範囲をリセット |
| `<leader>gS` | n | バッファ全体をステージ |
| `<leader>gR` | n | バッファ全体をリセット |

### プレビュー

| キー | 機能 |
|------|------|
| `<leader>gp` | hunk のプレビュー (ポップアップ) |
| `<leader>gi` | hunk のインラインプレビュー |

### blame / diff

| キー | 機能 |
|------|------|
| `<leader>gb` | 行の blame 表示 (誰がいつ変更したか) |
| `<leader>gd` | diff 表示 (HEAD との比較) |
| `<leader>gD` | diff 表示 (`~` = 前のコミットとの比較) |

### quickfix

| キー | 機能 |
|------|------|
| `<leader>gq` | バッファの変更箇所を quickfix に送る |
| `<leader>gQ` | 全バッファの変更箇所を quickfix に送る |

### トグル

| キー | 機能 |
|------|------|
| `<leader>gtb` | current line blame の ON/OFF |
| `<leader>gtd` | 削除行の表示 ON/OFF |
| `<leader>gtw` | word diff の ON/OFF |

### テキストオブジェクト

| キー | モード | 機能 |
|------|--------|------|
| `ih` | o, x | hunk を選択。`dih` で hunk 削除、`yih` で hunk ヤンク |

## キーバインド (diffview)

diffview のデフォルトキーマップ。パネルの種類ごとに割り当てが異なる。`g?` でその場に応じたヘルプ一覧が開くので、以下は主に使うものだけを挙げる。

### 共通 (ファイルパネル / ファイル履歴パネル)

| キー | 機能 |
|------|------|
| `<CR>` / `o` / `l` | カーソル位置のエントリの diff を開く |
| `j` / `k` | エントリ間を移動 |
| `<Tab>` / `<S-Tab>` | 次/前のファイルの diff を開く |
| `[F` / `]F` | 最初/最後のファイル |
| `gf` | 元のタブページでそのファイルを開く |
| `<leader>e` | ファイルパネルにフォーカス |
| `<leader>b` | ファイルパネルの表示/非表示 |
| `g<C-x>` | レイアウト切替 |
| `g?` | ヘルプ |

### ファイルパネル (`:DiffviewOpen`)

| キー | 機能 |
|------|------|
| `-` / `s` | エントリをステージ/アンステージ |
| `S` | 全エントリをステージ |
| `U` | 全エントリをアンステージ |
| `X` | 左側の状態にファイルを戻す |
| `L` | コミットログを表示 |
| `i` | list 表示と tree 表示を切替 |
| `R` | ファイル一覧を再読込 |

### ファイル履歴パネル (`:DiffviewFileHistory`)

| キー | 機能 |
|------|------|
| `<CR>` | そのコミットの変更ファイル一覧を開く |
| `<C-A-d>` | そのコミットを独立した diffview タブで開く |
| `L` | コミットメッセージ全文 |
| `y` | コミットハッシュをコピー |
| `X` | そのコミット時点の状態にファイルを戻す |
| `g!` | オプションパネル (`--follow` や `diff_merges` を切替) |

### マージコンフリクト解決時

| キー | 機能 |
|------|------|
| `]x` / `[x` | 次/前のコンフリクトにジャンプ |
| `<leader>co` / `<leader>ct` / `<leader>cb` | ours / theirs / base を採用 |
| `<leader>ca` | 全バージョンを残す |
| `dx` | コンフリクト領域を削除 |

`<leader>c` 系は大文字 (`<leader>cO` 等) にするとファイル全体に適用される。

## 典型的なフロー (gitsigns)

```
]c          → hunk を巡回
<leader>gp  → 変更内容を確認
<leader>gs  → 良ければステージ
<leader>gr  → 不要ならリセット
```

## 典型的なフロー (diffview)

### ブランチ間の差分を見る

```
:DiffviewOpen main..feature   → 2つのブランチの全体差分
<CR>                          → ファイルを選んで中身を見る
<Tab>                         → 次のファイルへ
:DiffviewClose
```

積み上げたブランチ列 (A→B→C) をレビューするときは、隣接する2つを順に渡していく。

### コミット単位で追う

```
:DiffviewFileHistory --range=main..feature
<CR>        → コミットを選ぶと、そのコミット単体の変更ファイルが出る
L           → コミットメッセージを確認
<C-A-d>     → そのコミットを独立したタブで開く
```

`<C-A-d>` の比較対象は常に親コミット。離れた2コミットを比べたいときは `y` でハッシュをコピーして `:DiffviewOpen <hash1>..<hash2>` に渡す。

### 未コミットの変更を確認する

```
:DiffviewOpen   → 作業ツリーと HEAD の差分
<CR>            → ファイルごとに確認
-               → ファイル単位でステージ
```

hunk 単位で選りたいときは gitsigns 側 (`<leader>gs`) を使う。
