対象ツール: $ARGUMENTS

以下の手順でワークフロードキュメントを拡充してください。

## 手順

### 1. 既存ドキュメントの確認
- メモリの `workflow-docs.md` を読み、ドキュメント整備の規約を確認する
- 対象ツールの設定ファイルを特定する (例: `dotfiles/<tool>/`)
- 対象ツールの既存ドキュメント (`docs/`) があれば読む

### 2. 設定ファイルの分析
- 対象ツールの設定ファイルを全て読む
- キーバインド、プラグイン、カスタム設定を洗い出す
- ドキュメント化されていない機能があれば記録する

### 3. ドキュメント整備
既存ドキュメントがない場合は以下の構造で新規作成:
```
<tool>/docs/
├── README.md          ← ワークフローガイド + リンク集
├── cheatsheet.md      ← 覚える必要のあるものの分類一覧 (該当する場合)
└── plugins/           ← 機能別の詳細ドキュメント (必要な場合)
```

既存ドキュメントがある場合:
- README.md のワークフローセクションに不足しているシナリオがないか確認
- プラグインドキュメントに未記載の機能・キーバインドがないか確認
- cheatsheet.md が最新かどうか確認
- ユーザーに不足箇所を提案し、承認を得てから追記

### 4. DRY 原則の遵守
- プラグインドキュメントが正のソース
- README.md やチートシートではキーバインドの詳細を繰り返さず、リンクで参照する

### 5. メモリの更新
- `workflow-docs.md` の「既存のドキュメント一覧」テーブルを更新する

## 注意
- デファクトスタンダードから外れた設定を見つけた場合はユーザーに報告する
- ドキュメントの変更前に方針をユーザーに確認する
- 設定ファイルの修正が必要な場合も事前確認する
